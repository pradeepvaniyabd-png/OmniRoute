# Benny's Gentle Adventure — A Calm & Joyful Journey

A ~2:19 children's animated short (16:9, 1920×1080, 30 fps, YouTube-ready). It is generated
entirely from code: vector art on Canvas, neural TTS narration, and synthesized music.

## Story & script

| # | Scene | What happens |
|---|-------|--------------|
| 0 | Title | "Benny's Gentle Adventure — A Calm & Joyful Journey", Benny waves |
| 1 | Treehouse (outside) | Morning sun rises; Benny is asleep in the window of his treehouse |
| 2 | Treehouse (inside) | A sunbeam says hello, Benny stretches: *"Good morning, sunshine!"* |
| 3 | Meadow | Benny walks, **counts 5 butterflies with the viewer**, smells a pink flower |
| 4 | Meeting Bunny | A little bunny who hopped too far; Benny offers help and **shares strawberries** |
| 5 | Bunny family | They follow the path to the big oak; family hug; *"You are a kind friend."* |
| 6 | Sunset walk | Pink-orange-gold sky, Benny hums his way home |
| 7 | Evening window | First stars twinkle: *"Being kind makes everyone smile."* |
| 8 | Ending | *"Keep smiling, keep learning, and remember to be kind! See you next time!"* |

The full narration text lives in `SCRIPT` inside `audio.py`. Captions are exported as `subtitles.srt`.

**Safety and tone:** pastel palette only. There are no dark scenes, no sudden cuts (1.2 s soft
crossfades and a gentle chime), no scary faces, and the "lost" moment is framed positively
("I hopped a little too far").

## Pipeline

```
audio.py   → Kokoro TTS voices (narrator / Benny / Bunny / Mama) + music-box lullaby
             + ducking → mix.wav, timeline.json (cue timings), subtitles.srt
scene.html → deterministic renderFrame(t) — every character is one reusable draw function
             (drawBenny, drawBunny…) so designs stay consistent across scenes
render.mjs → headless Chromium renders frames (4 workers) → x264 segments → video.mp4
build.sh   → runs everything + final mux (loudnorm −14 LUFS / −1.5 dBTP, AAC 192k) + thumbnail
```

## Build

```bash
pip install kokoro-onnx soundfile numpy
./build.sh                 # outputs to ./out (override with OUT=/path)
node render.mjs --stills 3,40,95   # quick QA stills
```

Outputs: `out/Bennys_Gentle_Adventure_1080p.mp4`, `out/subtitles.srt`, `out/thumbnail.png`.
